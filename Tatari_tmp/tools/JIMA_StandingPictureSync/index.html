JIMA 立繪清單同步

編輯前開啟一次，選擇包含 game.rmmzproject 的專案資料夾。保留此視窗，之後儲存立繪設定便會自動同步事件下拉選項。

尚未選擇專案

請使用 Microsoft Edge 或 Google Chrome。

    1. 在插件的「立繪個別樣式」新增、移除或換圖，逐層按「確定」，再按 Ctrl+S 儲存專案。
    2. 此視窗會顯示同步結果；只列出已登錄的立繪，不會把資料夾內其他圖片加入清單。
    3. 回到 MZ 插件管理器，對 Jima_StandingPicture 按右鍵選「重新整理／Refresh」，關閉並重新開啟插件命令參數視窗。

    若 MZ 仍顯示舊選項，儲存後重新開啟專案。未開此工具時，本機試玩啟動會補同步一次；之後仍需讓 MZ 重新讀取選項。
